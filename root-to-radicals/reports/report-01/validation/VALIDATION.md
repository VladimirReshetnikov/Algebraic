# Validation record

## Executed

Python 3.13; SymPy 1.14.0. The final `unittest.log` records **20 named tests passing** (41.461 seconds in the recorded run). Several tests contain multiple polynomial subcases. No arbitrary decimal tolerance is used to accept a positive mathematical answer.

The general constructive Galois code was run on quadratics, three different cubic groups/embeddings, two quartics, a pure quintic, and a cyclic quintic. The largest **completed and certified general positive** absolute field in this validation set has degree 20. `cyclic_quintic.json` and `binomial_quintic.json` were generated by the general constructor; the regression suite rechecks both saved certificates. Their earlier elapsed-time logs were captured during parallel exploratory runs and are not standardized benchmarks.

Both original problem polynomials were solved through their structural reductions. Their saved JSON results contain all six and all five conjugates, respectively, and select the roots specified in the question using Python indices 1 and 4. All eight conjugates of a notebook octic were also produced and certified. `notebook_octic.json` and its log record that result.

Tests cover exact branch boundaries, tampered branch numbers, wrong conjugate indices, invalid output expressions, missing AST references, rational/inexact input validation, reducible and repeated-root inputs, default JSON verification, worker timeouts, and both field-degree and enumeration limits.

Negative results exercised in the test suite use the exact small-degree Galois backend for `x**5-x-1` and a modular transposition witness for `x**7-x-1`. The full general negative-certificate path is implemented and explained, but was not exercised by constructing a large nonsolvable splitting field in this environment.

## Incomplete exploratory runs

`original_sextic.log` and `original_quintic.log` are **partial logs, not success records**. These were forced general-construction runs launched under an external 480-second limit, before using the compact methods. Neither produced a finished certificate within that limit. The sextic reached absolute degree 48 and automorphism enumeration; the quintic reached absolute degree 40 and embedding certification. They are retained to document practical limits rather than omitted from the evidence.

## Not executed

The Wolfram adapter and `.wlt` suite were not executed. Both the connected Wolfram context tool and its evaluator returned HTTP 404; no local Wolfram kernel was present. No claim of Wolfram runtime validation is made.

## Reproduction

From the package root: `python -m unittest discover -s tests -v`.

Recheck a saved certificate: `python python/cli.py --verify-file validation/cyclic_quintic.json --timeout 120`.

A successful finite test set supports, but does not prove, absence of implementation bugs. The theoretical completeness argument is in the article; the software has exact-arithmetic dependency assumptions and practical resource limits.
