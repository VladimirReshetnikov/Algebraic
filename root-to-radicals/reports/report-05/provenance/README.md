# Original source material

`FindExtension.nb` is byte-for-byte identical to the notebook in the uploaded
`FindExtension.zip`. SHA-256 hashes identify both original inputs. The notebook
was inspected as data, not evaluated. It is not a runtime dependency.

`notebook-inputs.txt` is a non-evaluating, best-effort rendering of 218 Input cells.
It is not an executable Wolfram source conversion: some box forms remain literal,
and the extraction scanner encountered 45 box-tree parse errors. Consult the
original notebook for authoritative syntax, formatting, and cached results.

The new package's MIT-0 license does not change rights in the supplied notebook.
