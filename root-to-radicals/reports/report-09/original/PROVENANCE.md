# Original input

`FindExtension.nb` was extracted without modification from the `FindExtension.zip`
archive supplied by Vladimir Reshetnikov with this request. It is retained as
research provenance, not as part of the newly licensed implementation.

Related question:
https://mathematica.stackexchange.com/questions/34011/why-is-toradicals-not-able-to-handle-all-cases-is-there-a-workaround

`FindExtension-input-cells.txt` is a non-evaluating display-box transcription of
220 input cells. It includes the source line where each cell starts. It is not a
fully executable Wolfram Language conversion: unsupported display constructs are
retained visibly. The extractor is `tools/extract_notebook.py`.

The package was developed separately. The supplied notebook and its transcription
are not relicensed by the distribution's MIT-0 license. No notebook cells were
executed during extraction.
