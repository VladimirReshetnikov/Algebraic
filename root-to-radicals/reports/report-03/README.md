# RadicalRoots 0.1.0

**Exact radicals from algebraic roots**, prepared for Vladimir Reshetnikov,
8 September 2026.

Start with **`docs/article.pdf`** for the theory, proofs, examples, implementation
contract and limitations. Its editable source is `docs/article.tex`.

## What is implemented

Two cooperating conversion layers:

1. Structural reductions: degrees up to four, affine depression, powers,
   rational polynomial composition, generalized reciprocal symmetry, and
   Dickson polynomials. The Wolfram front end additionally accepts explicit
   radical extension hints and tries native `ToRadicals` first.
2. General Galois/Fourier descent: build the exact embedded splitting field,
   adjoin the necessary roots of unity, compute actual automorphisms, find a
   prime-index normal series, and reconstruct the selected value by Fourier
   resolvents and exact principal-root phase choices.

The returned expression must contain only rational constants, `I`, arithmetic
and rational powers. A result still containing `Root`, `AlgebraicNumber`,
`CRootOf`, trigonometric functions or floating-point constants is not a success.

**Completeness is an algorithmic theorem, not a practical guarantee for every
input.** With terminating exact field primitives and no resource bounds, the
construction decides radical solvability and constructs radicals when they
exist. The reference implementation relies on CAS primitives, can hit backend
limitations, and uses finite default budgets. Full splitting fields are often
prohibitively expensive. This is not a claim of a production-grade universal
solver, a shortest-expression algorithm, or a formally verified package.

## Wolfram Language usage

Load the extracted package directly:

```wl
Get["/path/to/RadicalRoots/Kernel/RadicalRoots.wl"];

r = Root[-1 - #^2 - #^3 + #^4 + #^6 &, 2];
e = RadicalRoot[r, "Method" -> "Fast"];
RadicalExpressionQ[e]
RadicalEqualQ[e, r]

report = RadicalRootReport[r];
report["Status"]
report["Expression"]
```

`RadicalRoot` returns the expression or a `Failure`. `RadicalRootReport`
returns status, method, verification flag and diagnostic details.

| Option | Default | Meaning |
|---|---|---|
| `"Method"` | `Automatic` | `Automatic`, `"Fast"`, or `"Galois"` |
| `"TimeConstraint"` | `120` | Wall-clock seconds, or `Infinity` |
| `"MaxFieldDegree"` | `64` | Degree cap, or `Infinity` |
| `"MaxNodes"` | `10000` | Fourier recursion-node cap, or `Infinity` |
| `"MaxDepth"` | `30` | Fast-transformation depth cap, or `Infinity` |
| `"ExtensionHints"` | `{}` | A compositum generated by explicit radicals |

For example:

```wl
RadicalRootReport[r, "ExtensionHints" -> {Sqrt[2], 3^(1/3)}]
```

To request general descent without the implemented caps:

```wl
RadicalRootReport[r, "Method" -> "Galois",
  "TimeConstraint" -> Infinity,
  "MaxFieldDegree" -> Infinity,
  "MaxNodes" -> Infinity,
  "MaxDepth" -> Infinity]
```

Removing caps can consume very large resources and does not remove backend or
system limitations. Initial normalization may already produce radicals, in
which case even `"Galois"` can return an `AlreadyRadical` result.

Run the supplied native tests on a machine with a kernel:

```sh
wolframscript -file tests/run_wolfram.wls
```

## Python usage

From the extracted `RadicalRoots` directory:

```sh
python -m pip install -r python/requirements.txt
python examples/original_examples.py
python examples/embedded_model.py
python tests/run_tests.py --timeout 40
```

For direct imports, add the `python` directory to `sys.path` or `PYTHONPATH`:

```python
import sys
sys.path.insert(0, "/path/to/RadicalRoots/python")
import sympy as s
from radicalroots import to_radicals
x = s.Symbol("x")

r = to_radicals(x**6+x**4-x**3-x**2-1, 1, method="fast")
assert r.status == "Success" and r.verified
print(r.expression)

r = to_radicals(x**3-2, 0, method="galois")
print(r.status, r.expression, r.details)
```

Python root indices are **zero-based SymPy indices**, not Wolfram indices.
Do not translate arbitrary complex-root indices by subtracting one. The two
real-root correspondences used in the supplied original examples are justified
in the article.

Methods: `"auto"`, `"fast"`, `"galois"`. Positive integer budgets:
`max_field_degree=64`, `max_nodes=10000`, `max_depth=30`; `None` disables each.
There is **no solver-internal wall-clock limit**. Use an isolated process for
potentially long jobs; the regression runner demonstrates this pattern.

The public Python input is a nonconstant univariate polynomial with exact
rational coefficients and a valid index. A reducible polynomial is permitted:
only the selected root's minimal polynomial is solved. Invalid inputs raise
validation exceptions. `RadicalResult` fields are `status`, `expression`,
`method`, `verified`, and `details`.

The low-level `GaloisModel.from_field` interface accepts a verified embedded
Galois field already constructed in SymPy; see `examples/embedded_model.py`.
It does not accept an abstract group with guessed numerical root labels. A
nonsolvable oversized supplied field is not proof that its target element is
nonsolvable. The Python front end does not have Wolfram's extension-hint option.

## Meaning of outcomes

- `Success`: radical syntax and the chosen root were verified by the CAS.
- `NotSolvable`: an exact group computation proves nonsolvability of the
  selected root's minimal polynomial.
- `Unknown`: fast mode found no certified structural match.
- `ResourceLimit`: a budget was reached, not a proof of impossibility.
- `BackendError`: a backend operation or invariant check failed, not a proof
  of impossibility.

Verification is CAS-level, not a formal proof certificate. Python uses exact
minimal polynomials plus the separation-bound `Poly.same_root` test for the
selected embedding. Critical field embeddings use `field_isomorphism` with
`fast=False`, bypassing the default real PSLQ branch-choice heuristic.
Wolfram uses exact `RootReduce` equality. Numerical proximity is used only to
schedule fast candidates, never as their acceptance criterion.

## Original examples

For the positive real root of `x^6+x^4-x^3-x^2-1`, put

```
t = (1/2 + sqrt(849)/18)^(1/3)
y = t - 4/(3*t)
alpha = (y + sqrt(y^2+4))/2
```

The polynomial is `x^3*((x-1/x)^3+4*(x-1/x)-1)`.
For the largest root of `5*x^5-25*x^3+25*x+6`, put

```
u = ((-3+4*I)/5)^(1/5)       # principal complex fifth root
beta = u + 1/u
```

The inverse pair is chosen coherently. The article proves both identities and
identifies their branches without a numerical tolerance test.
