# Third unified analysis: the reviews of `StradFixed2.wl` and `StradFixed3.wl`

Main deliverables:

- `unified_analysis_C.pdf` — the report: the three reviews of the second
  corrected version (`../review-7`, `../review-8`, `../review-9`) compared and
  assessed, their findings consolidated with this session's observations into
  a catalogue of 22 issues, the design changes of the third corrected version
  `src/corrected/StradFixed3.wl`, the mathematics of its three coverage
  extensions (odd-index trace–norm criterion, square-class coset search,
  Honsbeek with rational summands), and the executed experiments.
- `unified_analysis_C.tex` — LaTeX source (ProveIt house style). Build with
  three passes of `pdflatex` from this directory; the appendix reads
  `../../corrected/StradFixed3.wl`.
- `tables/*.tex` — result tables generated by `harness/export_tables3.wl` from
  the recorded runs.
- `harness/` — every Wolfram script used: the unified-A/B battery plus the
  round-3 cases on the new version (`exp_battery3.wl`, `cases_new.wl`), the
  round-3 cases on `StradFixed2.wl` for the side-by-side columns
  (`exp_new2.wl`), fourteen randomized families (`exp_fuzz3.wl`), the probing
  scripts of `KNOWN_GAPS.md` (`probe_gaps3_*.wl`), the reviews' probes against
  `StradFixed2.wl` (`probe_reviews2.wl`), review-8's differential corpus on
  both versions (`differential3.wl`), a replay of the randomized inputs that
  times the slow ones (`repro_fuzz_slow.wl`), a runner for each review's own suite
  against its own proposal (`run_review_suite3.wl`), the table exporter and the
  shell chain `run_all.sh` that produced `logs/`. The scripts contain absolute
  paths at their top.
- `tests/StradFixed3.wlt` and `tests/run_tests.wls` — the regression suite
  (230 tests: unified-B's 144 rebound to the new context, the translated suites
  of the three reviews, and the controls of this document) and its
  fresh-kernel runner.
- `logs/*.txt` — raw transcripts of every run reported in the document.

The implementation itself is `src/corrected/StradFixed3.wl` (context
`RadicalDenest3\``); `src/corrected/README.md` documents its interface. The
second unified analysis, whose corrected version is reviewed here, is
`../unified-B`; the first is `../unified-A`.

Kernel used for every execution: 15.0.1 for Microsoft Windows (64-bit)
(July 2, 2026), one kernel at a time.
